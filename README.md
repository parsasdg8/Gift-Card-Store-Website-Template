## 📌 About The Project

DSgift is a front-end website template designed for an online gift card store.

The project includes a modern and responsive user interface for displaying and browsing different types of gift cards, including PlayStation, Steam, Xbox, and Apple gift cards.

This project was created for educational and portfolio purposes.

---

## ✨ Features

- 🎨 Modern and clean user interface
- 📱 Fully responsive design
- 🛍️ Gift card store layout
- 🔍 Product search interface
- 🏷️ Product category filtering
- 🎮 PlayStation gift cards
- 🎮 Steam gift cards
- 🎮 Xbox gift cards
- 🍎 Apple gift cards
- 📦 Dynamic product rendering with JavaScript
- 📱 Responsive mobile navigation menu
- 🔐 Trust and guarantee section
- 🎯 Call-to-action sections

## 🛠️ Technologies Used

This project was built using:

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Font Awesome

## ⚙️ JavaScript Features

JavaScript is used to handle several interactive parts of the website:

- Dynamic product rendering
- Product category filtering
- Mobile menu functionality
- Responsive navigation behavior
- Window resize handling
