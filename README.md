# Gift Card Store Website Template

A modern, clean, and responsive Gift Card Store website template built with HTML, CSS, JavaScript, and Tailwind CSS.

This project is designed as a front-end website template for online gift card stores, with a clean user interface and responsive layout for different screen sizes.

[🇮🇷 مشاهده نسخه فارسی](README_FA.md)

---

## ✨ Features

- 🎁 Modern Gift Card Store design
- 📱 Fully responsive layout
- 🎨 Clean and modern UI
- 🌙 Dark / Light mode
- 🛒 Product cards and gift card categories
- 🔍 Search and filtering interface
- ⚡ Fast and lightweight front-end
- 📐 Responsive design for desktop, tablet, and mobile
- 🎨 Built with Tailwind CSS
- 🧩 Reusable UI components

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Node.js / npm
