# Gift Card Store Website Template

A modern, clean, and responsive Gift Card Store website template built with HTML, CSS, JavaScript, and Tailwind CSS.

This project is designed as a front-end template for online gift card stores, featuring a modern user interface, responsive design, dark/light mode, and a simple development setup.

## 📋 Requirements

Before running the project, make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm

npm is included automatically with Node.js.

You can check whether Node.js and npm are installed by running:

```bash
node -v
npm -v

If both commands return a version number, your environment is ready.

🚀 Installation
1. Clone the repository

Open your terminal and run:

git clone https://github.com/parsasdg8/Gift-Card-Store-Website-Template.git
2. Navigate to the project directory
cd Gift-Card-Store-Website-Template
3. Install dependencies

Run:

npm install

This command reads the project's package.json file and installs all required dependencies.

It will also automatically create the node_modules folder.

You do not need to download or upload the node_modules folder manually.

4. Start the development server

Run:

npm run dev

After the development server starts, open the local URL shown in your terminal.

🎨 Tailwind CSS

This project uses Tailwind CSS for styling and responsive UI development.

Tailwind CSS is included as a project dependency, so you do not need to install it globally or separately.

Running:

npm install

will automatically install Tailwind CSS and the other required packages.

📦 Dependencies

All project dependencies are defined in:

package.json

The exact installed versions are stored in:

package-lock.json

If you clone the project on another computer, simply run:

npm install

to install all required packages and recreate the node_modules folder.
