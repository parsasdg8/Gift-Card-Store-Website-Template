# قالب فروشگاه گیفت کارت

یک قالب مدرن، تمیز و ریسپانسیو برای وب‌سایت فروش گیفت کارت که با HTML، CSS، JavaScript و Tailwind CSS ساخته شده است.

این پروژه به عنوان یک قالب Front-End برای فروشگاه‌های آنلاین گیفت کارت طراحی شده و دارای رابط کاربری مدرن و طراحی واکنش‌گرا برای اندازه‌های مختلف صفحه نمایش است.

[🇬🇧 English Version](README.md)

---

## ✨ امکانات

- 🎁 طراحی مدرن فروشگاه گیفت کارت
- 📱 طراحی کاملاً ریسپانسیو
- 🎨 رابط کاربری تمیز و مدرن
- 🌙 حالت تاریک و روشن
- 🛒 کارت‌های محصول و دسته‌بندی گیفت کارت‌ها
- 🔍 رابط جستجو و فیلتر محصولات
- ⚡ رابط کاربری سبک و سریع
- 📐 سازگار با دسکتاپ، تبلت و موبایل
- 🎨 استفاده از Tailwind CSS
- 🧩 ساختار مناسب برای توسعه و استفاده مجدد از بخش‌های رابط کاربری

## 🛠️ تکنولوژی‌های استفاده شده
