## 📌 درباره پروژه

DSgift یک پروژه فرانت‌اند و قالب فروشگاه اینترنتی گیفت کارت است.

در این پروژه یک رابط کاربری مدرن و واکنش‌گرا برای نمایش و فروش انواع گیفت کارت طراحی شده است.

محصولات موجود در قالب شامل گیفت کارت‌های پلی‌استیشن، استیم، ایکس‌باکس و اپل هستند.

این پروژه با هدف آموزشی و استفاده در نمونه‌کار ساخته شده است.
