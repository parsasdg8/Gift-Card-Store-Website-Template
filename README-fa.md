



# قالب وب‌سایت فروشگاه گیفت کارت

یک قالب مدرن، تمیز و ریسپانسیو برای وب‌سایت فروش گیفت کارت که با HTML، CSS، JavaScript و Tailwind CSS ساخته شده است.

این پروژه به عنوان یک قالب Front-End برای فروشگاه‌های آنلاین گیفت کارت طراحی شده و دارای رابط کاربری مدرن، طراحی ریسپانسیو، حالت تاریک و روشن و ساختار ساده برای توسعه است.

## 📋 پیش‌نیازها

قبل از اجرای پروژه، مطمئن شوید موارد زیر روی سیستم شما نصب شده باشند:

- [Node.js](https://nodejs.org/)
- npm

npm به صورت خودکار همراه Node.js نصب می‌شود.

برای بررسی نصب بودن Node.js و npm، ترمینال را باز کرده و دستورات زیر را اجرا کنید:

```bash
node -v
npm -v

اگر هر دو دستور یک شماره نسخه نمایش دهند، سیستم شما برای اجرای پروژه آماده است.

🚀 نصب و اجرای پروژه
1. دریافت پروژه

ابتدا Repository را Clone کنید:

git clone https://github.com/parsasdg8/Gift-Card-Store-Website-Template.git
2. ورود به پوشه پروژه
cd Gift-Card-Store-Website-Template
3. نصب وابستگی‌ها

دستور زیر را اجرا کنید:

npm install

این دستور فایل package.json را بررسی کرده و تمام وابستگی‌های موردنیاز پروژه را نصب می‌کند.

همچنین پوشه node_modules به صورت خودکار ایجاد خواهد شد.

نیازی نیست پوشه node_modules را به صورت دستی دانلود یا در GitHub آپلود کنید.

4. اجرای پروژه

برای اجرای Development Server دستور زیر را اجرا کنید:

npm run dev

پس از اجرای سرور، آدرس Local که در ترمینال نمایش داده می‌شود را در مرورگر باز کنید.

🎨 Tailwind CSS

در این پروژه از Tailwind CSS برای طراحی رابط کاربری و ایجاد صفحات ریسپانسیو استفاده شده است.

Tailwind CSS به عنوان یکی از وابستگی‌های پروژه در نظر گرفته شده و نیازی به نصب جداگانه یا نصب Global آن نیست.

با اجرای:

npm install

Tailwind CSS و سایر پکیج‌های موردنیاز به صورت خودکار نصب خواهند شد.

📦 وابستگی‌های پروژه

تمام وابستگی‌های پروژه در فایل زیر مشخص شده‌اند:

package.json

نسخه دقیق پکیج‌های نصب‌شده نیز در فایل زیر ذخیره شده است:

package-lock.json

اگر پروژه را روی یک کامپیوتر دیگر Clone کردید، فقط کافی است دستور زیر را اجرا کنید:

npm install

با این کار تمام پکیج‌های موردنیاز نصب شده و پوشه node_modules نیز دوباره ایجاد می‌شود.
